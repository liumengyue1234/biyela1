## 摘要

松材线虫病是由松材线虫引起的重大森林病害，具有传播速度快、致死率高的特点，对我国森林生态系统造成严重威胁。传统的松材线虫病检测方法主要依赖人工镜检，效率低且主观性强，难以满足大规模检测需求。

针对上述问题，本文设计并实现了一套基于深度学习的CT图像松材线虫病自动检测系统。该系统采用B/S架构，前端使用Vue3框架构建用户交互界面，后端采用Spring Boot框架提供RESTful API服务，深度学习模型基于PyTorch框架实现。系统集成了三种先进的深度学习模型：改进U-Net、Mask R-CNN和YOLO，用于CT图像中松材线虫的自动检测与分割。

在模型改进方面，本文对经典U-Net架构进行了多维度优化：引入CBAM（Convolutional Block Attention Module）注意力机制以增强特征表示能力；添加残差连接改善梯度流动；采用注意力门控改进跳跃连接；引入深度监督加速收敛。实验结果表明，改进后的U-Net模型在测试集上达到了89.5%的准确率和82.3%的平均IoU，优于Mask R-CNN和YOLO模型。

系统功能包括图像上传与管理、模型选择与检测、训练任务管理、历史记录查询以及多模型性能对比分析。系统采用MySQL数据库存储检测记录和训练历史，支持Docker容器化部署，具备良好的可扩展性和可维护性。

综上所述，该系统能够实现松材线虫病的快速、准确检测，为林业部门提供有效的辅助决策工具，具有重要的应用价值和社会意义。

**关键词**：松材线虫病；CT图像；深度学习；U-Net；目标检测

## Abstract

Pine wilt disease, caused by the pine wood nematode (Bursaphelenchus xylophilus), represents a severe forest disease with rapid transmission and high mortality rates, posing a significant threat to forest ecosystems in China. Traditional detection methods relying on manual microscopy suffer from low efficiency and strong subjectivity, making it difficult to meet the demands of large-scale detection.

To address these issues, this paper designs and implements an automatic detection system for pine wilt disease in CT images based on deep learning. The system adopts a B/S architecture, with Vue3 framework for the frontend user interface and Spring Boot framework for the backend RESTful API services. The deep learning models are implemented based on the PyTorch framework. The system integrates three advanced deep learning models: improved U-Net, Mask R-CNN, and YOLO for automatic detection and segmentation of pine wood nematodes in CT images.

In terms of model improvement, this paper optimizes the classic U-Net architecture through multiple dimensions: introducing CBAM (Convolutional Block Attention Module) attention mechanism to enhance feature representation capability; adding residual connections to improve gradient flow; adopting attention gating to improve skip connections; and introducing deep supervision to accelerate convergence. Experimental results show that the improved U-Net model achieves 89.5% accuracy and 82.3% mean IoU on the test set, outperforming Mask R-CNN and YOLO models.

The system features include image upload and management, model selection and detection, training task management, historical record queries, and multi-model performance comparison analysis. The system uses MySQL database to store detection records and training history, supports Docker containerized deployment, and possesses good scalability and maintainability.

In summary, this system can achieve rapid and accurate detection of pine wilt disease, providing an effective decision-support tool for forestry departments, with significant application value and social significance.

**Keywords**: Pine Wilt Disease; CT Image; Deep Learning; U-Net; Object Detection

## 第1章 绪论

### 1.1 研究背景及意义

松材线虫病是由松材线虫（Bursaphelenchus xylophilus）引起的重大森林病害，是世界上最危险的森林病害之一[1]。松材线虫主要通过松墨天牛（Monochamus alternatus）传播，侵入松树后大量繁殖，导致松树水分输导组织阻塞和树脂分泌减少，最终造成松树枯死。松材线虫病具有以下特点：

（1）传播速度快：松材线虫可随天牛迁飞进行自然传播，也可通过人为运输带疫木材进行远距离传播；

（2）致死率高：感染松材线虫病的松树死亡率可达90%以上，一旦发病难以治愈；

（3）防治难度大：病原体隐藏在树干内部，早期症状不明显，发现时往往已大面积传播；

（4）经济损失严重：松材线虫病不仅造成森林资源损失，还影响木材加工、生态旅游等相关产业。

我国是世界上松材线虫病疫情最严重的国家之一。据国家林业和草原局统计，全国年均发生面积超过1000万亩，造成直接经济损失数十亿元。松材线虫病的快速检测和早期预警对于控制疫情传播、保护森林资源具有重要意义。

目前，松材线虫病的检测方法主要包括：

（1）形态学检测：通过显微镜观察松材线虫的形态特征进行鉴定，需要专业人员操作，效率较低；

（2）分子生物学检测（PCR）：通过DNA扩增技术检测松材线虫，灵敏度高但需要专业设备和技术人员；

（3）分离培养法：通过分离培养线虫进行鉴定，周期长，不适合快速检测。

近年来，计算机断层扫描（CT）技术在医学诊断领域取得了巨大成功。CT图像能够清晰显示物体内部三维结构，为无损检测提供了新的可能。将CT技术与深度学习相结合，可以实现松材线虫病的自动化、智能化检测，提高检测效率和准确性。

本研究的意义在于：

（1）提高检测效率：自动化检测系统可大幅缩短检测时间，满足大规模筛查需求；

（2）降低人工依赖：减少对专业人员的依赖，使基层工作人员也能进行有效检测；

（3）支持早期诊断：CT图像可检测松材线虫的早期侵入，实现早发现、早防治；

（4）推动技术进步：为林业病害检测提供新的技术方案，促进智慧林业发展。

### 1.2 国内外研究现状

深度学习技术在农业和林业领域的应用研究日益广泛，国内外研究人员在植物病虫害检测方面取得了显著进展。

在国内研究方面，刘鹏等[2]利用卷积神经网络对水稻病虫害图像进行分类，提出了一种改进的ResNet模型，在自建数据集上达到95%以上的准确率。王建国等[3]基于YOLOv5开发了小麦赤霉病检测系统，实现了田间环境的实时检测。张伟等[4]采用Mask R-CNN进行番茄叶片病害分割，为精准农业提供了技术支持。在松材线虫检测领域，李明等[5]提出了一种基于迁移学习的松材线虫病早期检测方法，利用预训练模型提取特征，结合SVM分类器进行诊断，准确率达到87%。陈强等[6]开发了一套基于图像处理的松材线虫自动识别系统，通过图像增强和特征提取提高了识别精度。

在国外研究方面，Singh等[7]系统综述了深度学习在植物病害检测中的应用，指出卷积神经网络是目前最有效的方法。Wang等[8]提出了一种多尺度特征融合的病害检测方法，在多个公开数据集上取得了优异性能。Johnson等[9]利用CT扫描和三维重建技术分析了木材内部的缺陷分布。Kawasaki等[10]开发了一套基于X射线成像的种子质量检测系统，实现了种子活力的快速评估。

在松材线虫检测技术方面，日本学者进行了大量研究。Kiyohara等[11]最早报道了松材线虫病，并建立了系统的研究方法。Togashi等[12]研究了松材线虫病的传播机制和流行规律。Futai等[13]利用微CT技术观察了松材线虫在松树体内的分布规律。韩国学者Kim等[14]开发了一套基于机器视觉的线虫自动计数系统，提高了检测效率。

综合国内外研究现状可以看出：

（1）深度学习技术在植物病虫害检测领域已取得显著成效，但在松材线虫病CT图像检测方面的研究相对较少；

（2）CT技术作为一种无损检测手段，在木材和种子质量检测中已有应用，但应用于松材线虫病检测的研究尚处于起步阶段；

（3）现有的松材线虫病检测方法多为单一模型，缺乏多模型对比分析和综合评估；

（4）缺乏一套完整的从数据采集、模型训练到系统部署的松材线虫病检测解决方案。

本研究旨在填补上述空白，构建一套完整的基于CT图像和深度学习的松材线虫病自动检测系统。

## 第2章 相关技术

### 2.1 系统开发技术

本系统采用B/S架构（Browser/Server，浏览器/服务器模式）进行开发。B/S架构将系统分为前端展示层、业务逻辑层和数据存储层，具有维护成本低、跨平台性好、扩展性强等优点。

#### 2.1.1 前端开发技术

本系统前端采用Vue3框架进行开发。Vue3是Vue.js的最新版本，相比Vue2具有以下优势：

（1）更好的性能：Vue3采用Proxy替代Object.defineProperty实现响应式，消除了Vue2中的诸多限制；虚拟DOM重写，mounting和patching效率更高；静态提升和缓存事件处理函数减少了不必要的重复渲染。

（2）更好的TypeScript支持：Vue3从设计之初就考虑了TypeScript的支持，提供了更好的类型推断和IDE支持。

（3）Composition API：新增的Composition API允许开发者更灵活地组织逻辑代码，提高了代码的可复用性和可维护性。

（4）更小的体积：通过Tree-shaking优化，未使用的功能不会增加最终打包体积。

本系统还使用了以下前端技术：

- **Element Plus**：基于Vue3的组件库，提供了丰富的UI组件，如表格、表单、对话框等，加速界面开发；
- **ECharts**：数据可视化库，用于绘制检测结果的统计图表和模型性能对比图；
- **Vue Router**：Vue官方路由管理器，实现SPA（单页面应用）的路由跳转；
- **Pinia**：Vue3官方推荐的状态管理库，用于管理全局状态。

#### 2.1.2 后端开发技术

本系统后端采用Spring Boot框架进行开发。Spring Boot是Spring框架的子项目，旨在简化Spring应用的创建和开发过程，具有以下特点：

（1）开箱即用：提供了大量的默认配置，开发者无需进行繁琐的配置即可快速启动项目；

（2）内嵌服务器：集成了Tomcat、Jetty等Servlet容器，无需单独部署WAR文件；

（3）自动配置：根据项目依赖自动配置Spring Bean，降低了配置复杂度；

（4）微服务支持：与Spring Cloud无缝集成，便于构建微服务架构。

本系统还使用了以下后端技术：

- **Spring Data JPA**：简化数据库操作，通过Repository接口自动实现CRUD功能；
- **MySQL**：关系型数据库，用于存储用户信息、检测记录、训练记录等数据；
- **Lombok**：通过注解简化Java代码，自动生成getter/setter、构造函数等；
- **PyTorch**：Python深度学习框架，用于模型训练和推理，通过RESTful API与后端集成。

### 2.2 CT技术

计算机断层扫描（Computed Tomography，CT）是一种利用X射线对物体进行断层扫描，通过计算机重建获得物体内部结构图像的无损检测技术。

CT技术的工作原理是：X射线源围绕物体旋转发射射线，射线穿透物体后被对面的探测器接收。由于物体内部不同组织对X射线的吸收率不同，探测器接收到的射线强度分布也不同。通过收集多个角度的投影数据，利用滤波反投影或迭代重建算法，可以重建出物体内部的三维结构图像。

CT技术在松材线虫病检测中具有以下优势：

（1）无损检测：无需破坏松木样本即可获得内部结构图像，适合活立木检测；

（2）三维成像：能够获取松木内部的三维结构信息，包括木质部、韧皮部、射线组织等；

（3）高分辨率：现代CT设备可达到微米级分辨率，能够清晰显示松材线虫的形态；

（4）定量分析：可对松材线虫的分布密度、体积等参数进行定量测量。

本系统接收的输入为松木CT扫描图像，通常为DICOM格式或标准图像格式（PNG、JPEG）。CT图像中，松材线虫表现为细长的低密度线状结构，与周围木质组织形成对比。

### 2.3 深度学习模型

本系统集成了三种先进的深度学习模型用于松材线虫检测：改进U-Net、Mask R-CNN和YOLO。

#### 2.3.1 U-Net模型

U-Net[15]是2015年提出的用于医学图像分割的卷积神经网络架构，其编码器-解码器结构能够实现像素级的图像分割。

U-Net的核心结构包括：

（1）编码器（下采样路径）：由多个卷积层和最大池化层组成，逐步提取图像特征并降低空间分辨率；

（2）解码器（上采样路径）：由反卷积层和卷积层组成，逐步恢复空间分辨率；

（3）跳跃连接：将编码器中相同层级的特征图与解码器连接，补充细节信息。

本文对经典U-Net进行了以下改进：

① **CBAM注意力机制**[16]：在编码器和解码器中引入通道注意力和空间注意力模块，增强模型对松材线虫特征的关注能力。通道注意力通过学习通道间的重要性权重，强化重要特征通道的响应；空间注意力通过计算空间位置间的关系，增强目标区域的特征表达。

② **残差连接**[17]：在每个卷积块中引入残差连接（Skip Connection），解决深层网络训练中的梯度消失问题，使网络能够更有效地学习。

③ **注意力门控**[18]：改进跳跃连接结构，使用注意力门控机制过滤无关的低级特征，只传递与目标相关的特征信息。

④ **深度监督**[19]：在多个解码层级添加辅助损失函数，加速模型收敛，提高分割精度。

#### 2.3.2 Mask R-CNN模型

Mask R-CNN[20]是Facebook AI Research于2017年提出的实例分割框架，在Faster R-CNN的基础上添加了分割分支。

Mask R-CNN的主要特点包括：

（1）两阶段检测：第一阶段生成候选区域（Region Proposal），第二阶段对候选区域进行分类、边界框回归和掩码预测；

（2）RoI Align：使用双线性插值替代RoI Pooling，解决了特征图与原始图像对齐的问题，提高了分割精度；

（3）多任务学习：同时学习分类、检测和分割三个任务，共享特征提取网络。

Mask R-CNN能够区分图像中不同个体的松材线虫，适合复杂场景下的检测任务。

#### 2.3.3 YOLO模型

YOLO（You Only Look Once）[21]是一种实时目标检测算法，其核心思想是将目标检测问题转化为回归问题，在单次前向传播中直接预测目标的位置和类别。

YOLO系列算法的主要优势包括：

（1）速度快：单阶段检测架构省去了候选区域生成的步骤，检测速度远快于两阶段方法；

（2）端到端训练：整个网络可以进行端到端训练，简化了训练流程；

（3）泛化能力强：学到的特征可以迁移到其他任务。

本系统使用YOLOv8版本，其网络结构包括：

（1）骨干网络（Backbone）：使用CSPDarknet结构，提取多尺度特征；

（2）颈部网络（Neck）：采用PANet（Path Aggregation Network）结构，实现多尺度特征融合；

（3）检测头（Head）：负责边界框预测和类别预测。

### 2.4 本章小结

本章介绍了松材线虫病检测系统开发过程中涉及的相关技术。前端开发采用Vue3框架，结合Element Plus组件库和ECharts可视化库构建用户界面；后端开发采用Spring Boot框架，提供RESTful API服务；深度学习模型基于PyTorch框架实现，集成了改进U-Net、Mask R-CNN和YOLO三种模型；CT成像技术为系统提供了高质量的输入数据。这些技术的有机结合，为系统的开发奠定了坚实的技术基础。

##### 4.2.3.2 改进U-Net网络结构

改进U-Net的网络结构如图4-10所示。

![图 4-10 改进U-Net网络结构图](docs/images/figure_4_10_unet_architecture.png)

改进U-Net的主要改进点：

（1）**CBAM注意力模块**：在编码器和解码器的每个卷积块后添加CBAM模块，包含通道注意力子模块和空间注意力子模块；

（2）**残差块**：将原来的卷积块替换为残差块，包含两个3×3卷积层和一个跳跃连接；

（3）**注意力门控**：在跳跃连接处使用注意力门控，通过学习权重过滤无关特征；

（4）**深度监督**：在解码器的第2、3、4层级添加辅助损失函数，加速收敛。

##### 4.2.3.3 模型性能指标

各模型的性能指标定义如下：

（1）**准确率（Accuracy）**：正确预测的样本数占总样本数的比例；

（2）**平均IoU（Mean Intersection over Union）**：预测框与真实框的交集与并集之比的平均值；

（3）**F1分数**：精确率和召回率的调和平均数；

（4）**精确率（Precision）**：预测为正的样本中真正为正的比例；

（5）**召回率（Recall）**：真正为正的样本中被预测为正的比例；

（6）**推理时间（Inference Time）**：模型处理单张图像所需的时间。

## 结论

本文设计并实现了一套基于深度学习的CT图像松材线虫病自动检测系统，主要工作及成果总结如下：

（1）构建了完整的B/S架构系统，前端使用Vue3框架提供友好的用户界面，后端使用Spring Boot框架提供RESTful API服务，实现了图像上传、检测、训练、记录查询和模型对比等功能。

（2）实现了三种深度学习模型的集成：改进U-Net、Mask R-CNN和YOLO。其中改进U-Net通过引入CBAM注意力机制、残差连接、注意力门控和深度监督等技术，显著提升了模型的特征提取能力和分割精度。

（3）在自建数据集上进行了实验验证，改进U-Net模型达到89.5%的准确率和82.3%的平均IoU，优于Mask R-CNN（87.3%准确率，79.8%IoU）和YOLO（85.8%准确率，76.5%IoU）。

（4）开发了完整的模型训练和评估流程，支持参数配置、进度监控和结果分析。

（5）系统支持Docker容器化部署，具备良好的可扩展性和可维护性。

综上所述，该系统能够实现松材线虫病的快速、准确检测，为林业部门提供有效的辅助决策工具，具有重要的应用价值和社会意义。
